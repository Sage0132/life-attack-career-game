# 生涯特攻隊：生涯探索與日期歷程

這是供學生與教師一起使用的靜態教學網頁。流程為「選出在乎的事 → 認識工作 → 整理探索問題與任務 → 產生探索報告」。

線上入口：https://sage0132.github.io/life-attack-career-game/

## 本次改版

- 保留原網站匯入的 40 張價值卡與 90 張職業卡，不修改卡牌資料檔。
- 價值卡支援「在乎／目前還好／還不確定」、前後翻頁、直接跳卡，以及可篩選的全卡總覽。回看時修改答案不自動跳走。
- 從選過的價值卡選最多 3 張優先卡；職業池完整開放搜尋，最多收集 6 張，再排最多 3 個探索方向。
- 取消自動補入學生未選的答案、燃料百分比、能力雷達圖及缺乏資料支持的職業適合度判讀。
- 報告整理本次選擇、待確認問題、課堂小探索，以及實際填寫的觀察；可下載文字、圖片，或列印成 PDF。
- 新增有日期的探索歷程、前後選擇比較，以及可下載／載入的作答備份。

卡片選擇與課堂延伸活動是探索材料，不代表能力、人格或職業適合度。沒有作答或尚未觀察的部分保留待確認。

## 開啟方式

使用 GitHub Pages 網址，或下載完整儲存庫後用瀏覽器開啟 `index.html`。網站不需要安裝套件或執行建置。

圖片匯出使用隨專案提供的 html2canvas 1.4.1；Google 字型無法連線時會使用系統中文字型。第三方授權見 `licenses/html2canvas-LICENSE.txt`。

## 修改與再次探索

- 當次修改：點上方步驟回去修改，再開啟探索報告並重新下載。
- 幾個月後再次探索：在「探索歷程」或任務基地選「保留上次，重新選工作」或「保留上次，重新看價值卡」。系統先保存前次，再建立新日期的作答。
- 沿用價值卡換工作時，本次任務與觀察留白；前次任務與觀察仍保留在舊紀錄。
- 換學生：按「開始新一份」。系統先保留目前作答，再建立空白作答。不要只改暱稱就交給下一位學生。
- 載入舊學生：在「探索歷程」依暱稱與日期選取紀錄，再繼續修改或開始新一次探索。同樣暱稱不會自動合併為同一位學生。

## 資料保存與備份

- 目前是同一個瀏覽器內的本機保存，沒有學生登入、雲端同步或行政網站整合。
- 最多保留 100 份探索歷程，另包含目前作答。100 份指探索次數，不是學生人數。
- 「下載作答備份」產生 JSON 檔，包含目前作答與已保留紀錄，之後可載入還原；報告圖片與文字不能還原作答。
- 備份可能包含多位學生的紀錄，請由老師保管。下載備份不會自動刪除本機紀錄，也不會騰出名額；合併載入仍以 100 份為限。
- 從本機 HTML 改用線上網站，或換裝置／瀏覽器時，請先從舊版下載作答備份，再到新版載入。

## 原始資料來源

沿用原版 README 的資料說明：價值卡 40 筆來自 `life-squad-86-cards.xlsx` 的「生涯卡」工作表；90 筆職業卡中，86 筆來自「職業憧憬卡」工作表，另 4 筆是先前討論新增的 AI 輔助職務。

`data/careerData.js` 的 `richValueId` 和 `strategySkill` 欄位保留原資料，但新版不以這些欄位推論學生能力或自動推薦特教策略。正式卡牌名稱、版本與使用範圍仍需由教師核對、補註。
